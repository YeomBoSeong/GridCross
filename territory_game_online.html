게임 설명

🎯 목표

16×16 보드의 모든 칸이 채워졌을 때, 더 많은 칸을 차지한 플레이어가 승리합니다.

✚ 기본 규칙 — 십자 점령

빈 칸을 클릭하면 그 칸과 바로 위·아래·왼쪽·오른쪽 칸(최대 5칸)이 내 영역이 됩니다.
대각선 칸은 포함되지 않습니다.

★ = 클릭한 칸  |  파란 칸 = 점령되는 5칸  |  회색 = 포함 안 됨 (대각선)

⚔️ 상대방 땅 빼앗기

상대방 칸에 인접한 빈 칸을 클릭하면, 십자 범위 안에 있는 상대방 칸이 내 영역으로 바뀝니다.
단, 상대방 칸을 직접 클릭할 수는 없습니다.

클릭 전

흰 테두리 = 클릭할 빈 칸
빨간 칸 = 상대방 영역

→

클릭 후

파란 칸 = 내 영역이 됨 (5칸)
대각선 모서리는 그대로

※ 이 예시에서 가운데 빈 칸을 클릭하면 상하좌우 4개의 빨간 칸이 모두 내 것이 됩니다.
대각선 모서리 4칸은 범위 밖이므로 그대로 상대방 영역으로 남습니다.

🔍 미리보기

  • 마우스를 올리면 클릭 시 영향받는 칸을 미리 확인할 수 있습니다.
  • 연한 파란색 = 새로 점령되는 빈 칸
  • 진한 파란색 테두리 = 빼앗게 되는 상대 칸

🌐 온라인 대전

  • 랜덤 매치메이킹 또는 유저 이름으로 직접 초대
  • 수당 20초 제한 — 시간 초과 시 자동 패배
  • 게임 도중 기권 가능 (레이팅 감소)
  • 상대방 연결 끊김 시 부전승 처리
